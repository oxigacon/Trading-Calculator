# Trading-Calculator

Простой и удобный калькулятор для расчета прибыли при торговле скинами CS2.

## Возможности
Калькулятор поддерживает два основных направления обмена:
1. **Сторонний сайт → Steam** (комиссия при продаже в Steam — 15%. Можно изменить)
2. **Steam → Сторонний сайт** (комиссия при продаже на стороннем сайте — 5%. Можно изменить)

Программа автоматически рассчитывает:
* Сумму комиссии
* Чистую сумму после продажи скина (за вычетом комиссии)
* Чистую прибыль/убыток: `(сумма продажи − комиссия) − сумма покупки`

## Как запустить

### Запуск скомпилированной версии (.exe)
Просто скачайте файл **`CS2_Trade_Calculator.exe`** из корня этого репозитория и запустите его. Установка дополнительных программ и Python не требуется.
Желательно создать папку и в нее закинуть EXEшник тк пр изменении параметров создастся файл настроек в одной с EXEшником директории. 

### Запуск из исходного кода
Для запуска скрипта у вас должен быть установлен Python 3.x.
1. Склонируйте репозиторий.
2. Запустите в терминале:
   ```bash
   python calculator.py
   ```
